# MWD ChatApp

Браузерный прототип чата на Vue 3, TypeScript и Vite. В одной комнате можно переключаться между Alex и Sam и отправлять сообщения от обоих участников. История хранится в памяти страницы и сбрасывается при перезагрузке.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Открой адрес, который напечатает Vite. Команда `npm run build` проверяет типы и собирает проект.

## Классы

| Класс | Поля | Методы |
| --- | --- | --- |
| `User` | `id`, `name` | Конструктор задаёт ID и имя участника |
| `Message` | `id`, `author`, `sentAt`, `text`, `editedAt` | `getText()`, `getEditedAt()`, `edit(text)`. Внутренний `validateText(text)` убирает пробелы по краям и отклоняет пустой текст |
| `ChatRoom` | `name`, `members`, `messages` | `join(user)`, `getMembers()`, `sendMessage(userId, text)`, `getMessages()`, `editMessage(userId, messageId, text)`, `searchMessages(query)` |

`src/App.vue` вызывает методы комнаты и обновляет интерфейс. Правила отправки и редактирования находятся в классах TypeScript.

## Демо на лабораторной

1. Отправь сообщение от Alex. В поле **Chat as** выбери Sam и ответь.
2. Нажми **Edit** у ответа Sam, измени текст и сохрани. Рядом со временем появится отметка **Edited**. Кнопка **Edit** доступна только у сообщений выбранного участника.
3. Введи часть нового текста в **Search messages**. Поиск покажет совпадения независимо от регистра. Очисти поле, чтобы вернуть всю историю.
